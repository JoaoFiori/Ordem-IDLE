Sobre este protótipo

Os elementos dos agentes seguem a sua definição. Classes, facções, estatísticas e habilidades ainda são marcações de design, não regras oficiais dos livros. Tudo fica no arquivo de dados e pode ser trocado. Os agentes usam pixel art 32x48 (DATA.SPRITES.png); os monstros são gerados por código. Ambos podem ser trocados por PNGs próprios (DATA.SPRITES.override). O progresso é salvo neste navegador.

Backup do progresso (texto): Exportar gera um código para você guardar; para restaurar, cole o código na caixa e use Importar.
